💾 Data manager
Your events are saved in your browser automatically. Export a backup before uploading a new version of this file — then import it back in one click to restore everything.
⬇ Export my events
Downloads a events-backup.json file to your computer. Keep this safe — it contains all your events. Do this before uploading a new version of the calendar.
⬆ Import events
Restore your events from a previously exported events-backup.json file. Your current events will be replaced with the imported ones.
📋 How to safely upgrade the calendar
1. Click Export above — save the file.
2. Upload the new index.html to GitHub.
3. Open your live URL, go to Data ➞ Import.
4. Select your saved events-backup.json.
All your events are restored instantly. ✓
